# Zenit

Zenit é uma plataforma de estudos (PWA) pensada para quem está se preparando para concursos e provas acadêmicas. O objetivo é centralizar organização, foco e progresso em um só lugar — sem depender de planilhas soltas ou vários apps diferentes.

🔗 Acesse: https://zenit-io.lovable.app/

## O que o Zenit oferece
Gestão de estudos: organização de matérias, tópicos e cronogramas de forma estruturada
Timer Pomodoro: ciclos de foco integrados à rotina de estudo
Grupos de estudo: espaço colaborativo para estudar em conjunto
Gamificação: mecânicas de progresso para manter a consistência
Recursos com IA: funcionalidades inteligentes de apoio ao estudo
PWA: funciona direto do navegador, instalável como app

## Tecnologias

Construído com Vite, TypeScript, React, shadcn-ui e Tailwind CSS.

## Rodando localmente

Pré-requisito: Node.js e npm instalados (instalar com nvm).

bash
git clone <https://github.com/evelinunes12-cell/zenit-io>
cd zenit-io
npm i
npm run dev
